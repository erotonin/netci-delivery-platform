# Support

Use GitHub Discussions for usage and design questions when enabled. Use GitHub
Issues for reproducible bugs and scoped enhancements. Security reports must use
the private process in `SECURITY.md`.

This community project provides no guaranteed response or service-level
agreement. Include the netCI commit, operating system, deployment profile,
relevant configuration with secrets removed, exact command, exit code and the
smallest useful log excerpt when asking for help.

Read `QUICKSTART.md` and `docs/troubleshooting.md` before filing an issue.
