## 4. Lỗi cần sửa — theo mức nghiêm trọng

### 🔴 4.1. `local_runner.py` bịa security evidence và bật mặc định

File: `backend/app/adapters/local_runner.py` (thêm ở commit `4d3a2b8`).

```python
digest = "sha256:" + hashlib.sha256(f"{run_id}-{commit}".encode()).hexdigest()   # dòng 136
...
"ciReport": {"testPassCount": 42, "testFailCount": 0, "coveragePercentage": 94.5,
             "vulnerabilityScan": "passed", "sastPassed": True, ...}               # dòng 353-359
...
f"[sign] Verification: VALID signature from netci-authority (SHA256 verified)"    # dòng 267
```

- **Digest bịa**: hash của chuỗi `"{run_id}-{commit}"`, không phải hash của artifact nào.
  Nó qua được regex `IMMUTABLE_DIGEST`, tạo deployment thật cho artifact không tồn tại.
- **CI report bịa**: `42 pass / 94.5% coverage / vulnerabilityScan passed` — đúng những
  con số hard-code tôi đã xoá khỏi `demo_data.py` ở Phase 1.
- **Log bịa**: ghi "VALID signature" khi không hề có chữ ký.
- **Bật mặc định**: `main.py:176` — chạy khi `NETCI_CI_MODE != jenkins`, không có
  `is_local_runtime()` guard. Production chỉ được cứu *gián tiếp* vì `ci_launcher.py`
  từ chối `CI_MODE=none` — nếu ai đó nới guard đó, evidence giả sẽ chảy vào production.
- Nuốt lỗi: `except Exception: logger.debug(...)`.

Đây chính là thứ tạo ra "14 lượt chạy thành công" trên screenshot.

**Sửa**: (a) đổi tên thành `simulated_ci.py` để tên nói đúng bản chất; (b) chỉ khởi động
khi `is_local_runtime() and NETCI_SIMULATED_CI=true` — **opt-in**, không opt-out;
(c) mọi run/version/evidence nó tạo phải mang cờ `"source": "simulated"` và UI phải
hiển thị nhãn "GIẢ LẬP"; (d) audit record `pipeline.simulated`; (e) test chứng minh nó
không khởi động ngoài local kể cả khi `ci_launcher` bị nới.

### 🔴 4.2. `/git/info` — NameError bị nuốt, trả dữ liệu hard-code

    res = subprocess.run(...)   # subprocess KHÔNG được import → NameError

    pass                        # nuốt → trả về "5a314b8" mãi mãi

**Sửa**: `import subprocess`; bỏ giá trị mặc định hard-code; nếu không lấy được thì
trả `{"commit": null, "reason": "git unavailable"}` — trung thực.

### 🔴 4.3. 13 route giấu khỏi OpenAPI, gồm remote-execute

`include_in_schema=False` làm test contract (`test_checked_in_contract_covers_every_live_http_operation`)
**không thấy** route đó → có thể thêm route mà không cập nhật `openapi.yaml`. Vi phạm
non-negotiable #9.

Đặc biệt nguy hiểm:
- `POST /api/v1/agents/execute` — **thực thi lệnh trên agent từ xa**. Ranh giới tin cậy
  lớn nhất hệ thống, không có trong contract, không rõ có test security regression.
- `GET /api/v1/agents/install.sh` — phát script cài agent.
- `POST /api/v1/security/waivers` — **thay đổi quyết định policy** (miễn trừ CVE).
- `POST /modules/{id}/config/apply`.

**Sửa**: bỏ `include_in_schema=False` khỏi tất cả trừ `/metrics`; đưa vào `openapi.yaml`;
viết security test cho `agents/execute` (ai gọi được, lệnh nào được phép, có audit
không); viết ADR cho agent daemon (mô hình tin cậy outbound WebSocket).
